# 重構驗收與防退步 (Refactor Acceptance)

**何時讀本文**：重構、瘦身或改寫既有技能；需要新舊比對、行為 A/B、故障注入，或工具尚未就緒需要手動檢查時。

---

## 1. 防退步稽核

比較對象一律是「重構前的原始版本」（取自 git 歷史，記錄 commit hash），不是重構後再被修改過的版本。

### 質問 1：有沒有退步？
1. **完工標準無損**：舊版要求的客觀驗收證據，在新版對應領域中被保留或等價承接。
2. **失敗出口保留**：`hold` / `blocked` / `in_progress` 等出口仍在；證據不足不得視為完成。
3. **分支與迴圈保留**：複雜度分支（SUBPLAN）與未達標回到實作的重試迴圈仍在流程中。
4. **前置約束時機不變**：前置條件仍在前置階段。
5. **特徵不遺漏**：舊版的反引號識別字、snake_case 詞、帶單位數值、CLI 指令、狀態值，在新版（含 `references/`）都找得到；覆蓋率達預先登記的門檻。

### 質問 2：路由與指令是否完整？
1. 外置內容在主約有條件式指針。
2. CLI 指令與參數保留可執行的具體形式；術語都在專案中確實存在。

### 質問 3：是否需要請示使用者？
整段刪除、預設行為改變、意圖不明的項目，列入清單，取得確認後才生效。

---

## 2. 特徵抽取（供 `diff_critic.py` 或手動比對）

| 類型 | 抽取方式 |
| :--- | :--- |
| 反引號識別字 | 所有 `` `...` `` 內容 |
| snake_case 詞 | 含底線的小寫識別字 |
| 帶單位數值 | 數字加 ms、s、px、KB、行、% 等單位 |
| CLI 指令 | 以 `python`、`git`、`node` 等開頭的指令行 |
| 狀態值 | `hold`、`blocked`、`in_progress`、`done` 等 |

門檻值先以試點資料校準，再寫入驗收表；校準前不要憑感覺設定。

## 3. 行為 A/B 驗收

### 預先登記（執行前寫定，不得事後調整）

| 欄位 | 內容 |
| :--- | :--- |
| 技能與領域 | |
| 舊版基準 commit hash | |
| 固定任務 | |
| 腳本可判定指標 | 例如：檔案是否存在、尺寸是否完整、時間戳先後、狀態值、刪除次數 |
| 通過標準 | 每項指標新版在每次執行都不低於舊版 |
| 每組執行次數 | 預設 3 次；低成本的腳本指標可加到 10 次 |

LLM 評分只作輔助參考，不列為通過條件。3 次的結果視為初步訊號，不做精確比率宣稱。

### 故障注入（正常任務測不到失敗路徑）

| 編號 | 注入 | 預期 |
| :-: | :--- | :--- |
| F1 | 不提供 CRITIC 裁決 | 狀態為 `hold` 或 `blocked`，不得為 `done` |
| F2 | Validator 第一次故意失敗 | 流程回到實作，迴圈次數 >= 1 |
| F3 | 提供被裁切成局部的 Contact Sheet | 被拒絕 |
| F4 | 要求刪除 `output_root` 外的路徑 | 被守門阻擋，無檔案被刪 |
| F5 | 任務複雜度超標 | 展開 SUBPLAN 並歸併 |

依技能領域挑選適用者；F1～F5 的預期行為需 3 次中 3 次達成。

### 負向禁令效果實驗（選用）
同一技能準備「正向版」與「保留原禁令版」各跑 3 次，只比較腳本可判定的指標。正向版在每個指標都不低於原版平均，才對 A 類禁令採用正向化；B 類不受此實驗影響。

## 4. 手動檢查清單（工具尚未就緒時）

- [ ] `git status --porcelain` 為空，已打 Tag，已記錄原始版本 commit hash。
- [ ] 控制字元掃描通過（排除 Tab、換行、回車）：

  ```
  [\x00-\x08\x0b\x0c\x0e-\x1f]
  ```

- [ ] 每個 code fence 成對；沒有行首異常缺字。
- [ ] 行數：主約 <= 500（目標 <= 150）。
- [ ] frontmatter 含 `name`、`description`、`allowed-tools`、`exit-profile`。
- [ ] 主約引用的相對路徑都存在（範例路徑已標為佔位符）。
- [ ] 禁令矩陣：未分配為 0；B 類都有守門與阻擋測試。
- [ ] 舊版的識別字、數值、指令、狀態值，逐項在新版中找到。
- [ ] 失敗出口、分支、迴圈、前置條件逐項對照過。
- [ ] 待刪清單已交使用者確認。

---

## 5. 回滾

```bash
# 單一技能
git checkout <tag> -- .agents/skills/<target-skill>/
```

- 整批失敗：還原該批所有技能目錄，再檢討比對工具與矩陣漏掉了什麼。
- `OMNISTATE State` 的狀態與快照只追加紀錄，不隨回滾刪除。
